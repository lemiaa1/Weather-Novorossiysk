# Прогноз осадков в Новороссийске Дз4 (только для избранных хаха >:)

Выполнила: Ачатова Амелия Павловна 
Группа: ИУСбд-01-23

Веб-приложение на Streamlit с моделью LightAutoML. По календарной дате и погоде предыдущих 20 дней прогнозирует наличие осадков на следующий день: есть/нет. Модель обучается на множестве таких примеров из исторического архива RP5, станция Новороссийск 37006.

## Возможности

- Работа со встроенным архивом или загруженным CSV RP5 Новороссийска.
- Просмотр данных, графиков и категорий осадков.
- Обучение модели, подбор порога и оценка качества на тестовых данных.
- Прогноз на день после выбранной даты с оценкой вероятности и сравнением с архивным фактом, если он доступен.

Категории «нет/небольшие/сильные» используются как признаки прошлых дней. Сам прогноз остаётся бинарным.

## Основные файлы

- `app.py` — интерфейс приложения.
- `weather_model.py` — подготовка данных, обучение, оценка и прогноз.
- `requirements.txt` — зависимости Python.
- `data/novorossiysk_rp5.csv` — архив погоды.
- `.streamlit/config.toml` — оформление и настройки.
- `tests/` — проверки данных и интерфейса.

## Запуск

Требуется Python 3.11. 

Команды выполняются в папке проекта. Однократная установка — пропустите этот блок, если окружение и зависимости уже настроены:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Запуск приложения:

```bash
source .venv/bin/activate
python -m streamlit run app.py
```
Браузер обычно открывается автоматически. Если этого не произошло, скопируйте адрес из строки Local URL в терминале и откройте его в браузере! 

Как пользоваться:
1. Выберите данные в левой панели. «Архив из проекта» открывает встроенный файл. Через «Загрузить CSV RP5» можно выбрать другой архив Новороссийска (тк сайт именно про новороссийск :3) в том же формате.
2. Задайте настройки. Кнопками − и + меняется граница сильных осадков. Для первого запуска оставьте 10 мм и выберите 60 секунд на подбор модели.
3. Посмотрите вкладку «Данные». Здесь показаны период наблюдений, количество дней, доля дней с осадками и разделение выборки. Ниже находятся график по месяцам и категории осадков. Нажмите «Посмотреть подготовленную таблицу», чтобы раскрыть записи.
4. Нажмите «Обучить LightAutoML». Дождитесь сообщения о завершении и откройте «Проверка модели». Там появятся показатели качества, количество верных прогнозов, матрица ошибок и график. Матрица показывает, сколько дней определено правильно, сколько осадков пропущено и сколько было ложных тревог.
5. Получите отдельный прогноз на вкладке «Прогноз дня». Выберите, по какую дату известна история, и нажмите «Получить прогноз на следующий день». Например, история до 19.07.2022 даст прогноз на 20.07.2022. Появятся ответ «Осадки ожидаются» или «Осадки не ожидаются», оценка вероятности и диаграмма. Если прогнозируемый день есть в выбранном ряду, ниже будет показан архивный факт для сравнения.

Для другой даты прогноза заново обучать модель не нужно: выберите дату и нажмите кнопку получения прогноза. После изменения данных или настроек обучения запустите обучение снова. Приложение работает с историческим архивом.

Остановка и повторный запуск
Модель хранится только в оперативной памяти: после остановки сервера она не сохраняется. Поэтому при следующем запуске снова нажмите «Обучить LightAutoML»!!
